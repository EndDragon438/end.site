 These popups have a specific structure (though that can be modified with modifications to the stylesheet)

 The structure includes a button to close the popup of course, in the top right.

 The structure of these popups can be modified a fair bit, they really just need a <div> next to a matching <input>.

 This is a little NoJS popup stylesheet, once again abusing <input> elements and labels. It's a pretty simple little system. It works by pairing up <input> and <div> elements, the latter of which are styled to take up the full viewport and also given a lil 'close' button. The inputs are checkboxes, and the close buttons along with the main 'open' buttons are <label> elements for those inputs. Really there could be any number of these, but I'm only demonstrating a single open and close button here.

 The inputs are always hidden, and by default the divs are hidden as well. When the inputs are checked (via the user clicking on the paired labels) their paired divs are set to display: block;. They already take up the whole viewport, and are given another label with the close icon (plain unicode!!), so then i can put whatever content in there i like.

 The stylesheet for this lil trick can be found here.
