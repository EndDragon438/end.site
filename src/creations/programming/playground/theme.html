NOTICE: i no longer use this theme switcher, and have swapped to a nearly JS-free version, the details for which you can find here. This page is kept around for archival purposes, and in case someone would still like to copy the (imo worse) implementation.

 As you may have noticed, i have a theme switcher! It's the lil dropdown in the bottom right of the site, if you open it up you'll see the themes i've currently got. It's a JavaScript widget i threw together, which uses localStorage to persist theme preferences across my site!

 Basically the way it works, is i've got the floating div over there which has a named radio button group to pick the theme. Each of those inputs has a value with the name of the theme in it, so in the script I grab the selected theme with a document.querySelector('input[name="theme"]:checked')?.value and pass it to my theme swapper. I also check if there's a theme already selected or not, and set the theme accordingly.

 The theme swapper itself is pretty simple. I've got a big dictionary (in Python terms) which for each theme stores the name of all the variables i use in my CSS, along with their values for that theme. The theme swapper iterates over the CSS variables and sets new values. That's it. Super easy. I also have the option of changing the background image (which i think i'll do as soon as a make some new ones) and i plan on making it so you can swap font sets too!

 Feel free to check out the source for the widget! It's on just about every page on this site, so you can find it pretty easily. It's right above the header in the code.

<script>
    // Allowed themes
    const themes = {
        colours: { // Colour themes
            default: 'dark',
            dark: {
                col_fg: '#ffffff',
                col_fg_light: '#ffffff',
                col_fg_lighter: '#ffffff',
                col_fg_alt: '#ffffff',
                col_bg: '#000000',
                col_bg_dark: '#000000',
                col_bg_light: '#111111',
                col_bg_lighter: '#222222',
                anchor: '#3f8aff',
                background: '#111111',
            },
            light: {
                col_fg: '#000000',
                col_fg_light: '#000000',
                col_fg_lighter: '#000000',
                col_fg_alt: '#000000',
                col_bg: '#ffffff',
                col_bg_dark: '#ffffff',
                col_bg_light: '#eeeeee',
                col_bg_lighter: '#dddddd',
                anchor: '#1200e8',
                background: '#dddddd',
            },
        },
        fonts: { // Font sets
            default: 'draconic',
            draconic: {
                main_font: '"Albertus MT", serif',
                bitmap_font: '"VCR OSD Mono", sans-serif',
                mono_font: '"Jack Input", monospace',
            },
            regular: {
                main_font: 'serif',
                bitmap_font: 'sans-serif',
                mono_font: 'monospace',
            }
        }
    }

    // Always set the variables on load
    changeTheme();
    // Change theme whenever the themepicker changes
    document.getElementById('themePicker').addEventListener('click', (event) => changeTheme())
    
    function changeTheme() {
        for (const theme of Object.keys(themes)) {
            // Value of the input for whichever theme we're working on
            let value = document.querySelector(`#themePicker input[name="${theme}"]:checked`)?.value;
            if (localStorage['data-' + theme]) {
                if (!Object.keys(themes[theme]).includes(value)) {
                    value = localStorage['data-' + theme];
                } else {
                    localStorage['data-' + theme] = value;
                }
            } else {
                // Set the theme to default if it's not usable
                if (!Object.keys(themes[theme]).includes(value)) {
                    value = themes[theme].default;
                }
                
                localStorage['data-' + theme] = value;
            }
            
            // Set appropriate variables
            for (const variable of Object.keys(themes[theme][value])) {
                document.body.style.setProperty(`--${variable.replaceAll('_', '-')}`, themes[theme][value][variable]);
            }
        }
    }
</script>
